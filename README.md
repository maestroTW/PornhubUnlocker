## PornhubUnlocker
## How it works?
Pornhub creates a full-screen popup with authorization information, but it can be easily removed by viewing the page code and deleting the lines with the id `age-verification-wrapper` and `age-verification-container`.
PHUnlocker works as an adblocker that simply removes these pieces of code.

## How to install?
1. Open Google Chrome
2. Go to the "Extensions"
3. In the upper right corner of the window that opens, find the "Developer mode" toggle switch and switch it to the "On" position
4. Click on "Load unpacked extension".
5. In the file manager, specify the PHUnlocker directory
